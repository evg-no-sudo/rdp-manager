# Linux RDP Manager

[English](README.en.md) · [Планы](ROADMAP.md)

**Разработчик:** Evgeny Anishchenkov

Нативный RDP-клиент на Rust, GTK4, libadwaita и FreeRDP. Основная проверенная среда — Linux Mint 22.3 Cinnamon/X11, серверы Windows RDP и Linux/xrdp. KDE Plasma, GNOME и нативный Wayland входят в целевую матрицу. Полный набор проверок для них ещё предстоит выполнить.

## Возможности

- Профили в SQLite, поиск, история и сворачиваемые папки. Сортировка внутри папок по числу успешных подключений или по имени. Выборочный импорт RDP-профилей и групп Remmina, клонирование профилей.
- Подключения во вкладках и отдельных окнах, возврат вкладки без переподключения, общий ряд кнопок и вкладок в полноэкранном режиме. **Ctrl+Shift+F11** переключает полный экран, правый **Ctrl** освобождает захват клавиш.
- Динамическое разрешение при поддержке сервера, режимы качества и H.264 с аппаратным декодированием при наличии совместимого GPU и драйвера. [Диагностика H.264](docs/H264.md)
- Двусторонний текстовый и файловый буфер, потоковая передача файлов и папок между RDP-сеансами, счётчик отправленных данных и опциональная общая папка. Для получения файлов через буфер на Linux нужен FUSE. Скорость больших передач зависит от сервера и сети.
- Воспроизведение удалённого звука. Экспериментальный микрофон включается через `RDP_MANAGER_MICROPHONE=1`; проверен на xrdp, совместимость с Windows требует доработки.
- Пароли в локальном Secret Service, проверка сертификатов сервера с возможностью запомнить доверие. Ручной зашифрованный обмен выбранными профилями через папку, WebDAV/Nextcloud или SFTP. Пароли RDP и назначения папок в обмен не входят. [Обмен](docs/TRANSFER.md) · [WebDAV](docs/WEBDAV.md) · [SFTP](docs/SFTP.md)
- Системная, светлая и тёмная тема. Интерфейс выбирает русский для русской системной локали и английский для остальных. **⋮ → Язык интерфейса** позволяет сохранить другой выбор. Перезапустите приложение, чтобы его применить.

## Установка

Первый пакет предназначен для Linux Mint 22.3, amd64. Он включает проверенную сборку FreeRDP/WinPR 3.32.2. Остальные зависимости устанавливает APT. После установки приложение доступно в меню как **Linux RDP Manager**.

```sh
sudo apt install ./target/dist/rdp-manager_0.1.0-25_amd64.deb
rdp-manager
```

## Сборка

Для разработки нужны Rust/Cargo, pkg-config, dev-пакеты GTK4 ≥ 4.14, libadwaita ≥ 1.5, FreeRDP ≥ 3.25, SQLite, libsecret, OpenSSL и zlib. Для сохранения паролей в пользовательском сеансе должен работать провайдер Secret Service.

```sh
cargo build --locked
cargo test --locked
```

Сборка движка с H.264, FUSE и PulseAudio, запуск и упаковка (для пакета нужен `dpkg-dev`):

```sh
sh scripts/build-h264.sh
sh scripts/run-h264.sh
sh scripts/build-deb.sh
```

Пакет и SHA-256 находятся в `target/dist/`. База профилей по умолчанию находится в `${XDG_DATA_HOME:-$HOME/.local/share}/rdp-manager/profiles.sqlite3`. См. [проверки](docs/TESTING.md) и [дорожную карту](ROADMAP.md).
