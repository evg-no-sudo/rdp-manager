# Ориентир: tiny-rdp-client

Исходный проект: tiny-rdp-client (версия 1.2.0,
коммит a276aeab). Это графическая оболочка Python/Tk для отдельного процесса
`xfreerdp3`. Наш клиент остаётся Rust/GTK с собственным окном RDP и встроенной
библиотекой FreeRDP, поэтому аргументы командной строки не переносим напрямую:
для каждого устройства подключаем соответствующий канал FreeRDP.

| Возможность | Текущее состояние | Следующий шаг |
| --- | --- | --- |
| Профили, история, несколько сеансов, отдельные окна | Есть | Избранное и группировка |
| Поиск подключений | Есть | Проверить удобство на больших списках |
| Разрешение по размеру окна, режимы графики, AVC444 | Есть | Проверить Windows, xrdp и Wayland |
| Пароли Secret Service, сертификат с запоминанием | Есть | Добавить управляемые режимы аутентификации |
| Ввод, переключение раскладки и захват клавиш | Есть | Проверить автоматический захват на X11 и Wayland |
| Автопереподключение | Нет | Добавить с ограничением попыток и явной отменой |
| Двусторонний текстовый буфер | Реализован CLIPRDR для Unicode | Проверить на Windows и xrdp, затем большие фрагменты |
| Передача файлов через буфер | В обе стороны через CLIPRDR. Приём через FUSE в одном сеансе | Поддержать приём в нескольких сеансах |
| Перенаправление папок и принтеров | Одна локальная папка через RDPDR; принтеров нет | Проверить передачу файлов на Windows/xrdp, затем несколько папок и принтеры |
| Звук и микрофон | Воспроизведение через RDPSND проверено. Микрофон через AUDIN включается для запуска через `RDP_MANAGER_MICROPHONE=1` | Проверить запись на Windows/xrdp |
| USB и смарт-карты | Нет | Опционально, после папок и звука; отдельные разрешения |
| Полный экран, несколько мониторов | Нет | Проверить с GTK/X11/Wayland и динамическим разрешением |
| Журнал сеанса и диагностика | Частично | Без секретов; видимые ошибки и codec/FPS |
| DEB-пакет и desktop-файл | Нет | После стабилизации базовых каналов |

Приоритет реализации: (1) текстовый буфер, (2) файлы и папки, (3) звук и
полный экран, (4) принтеры и микрофон, (5) USB/смарт-карты и пакетирование.
Пароли остаются только в локальном Secret Service. Режим «игнорировать ошибки
сертификата» из tiny-rdp-client не берём за значение по умолчанию: у нас уже
есть подтверждение и запоминание сертификата конкретного сервера.
