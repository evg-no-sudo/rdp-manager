# Дорожная карта

[English](ROADMAP.en.md) · [Описание проекта](README.md)

## Ближайшие задачи

1. Проверить установку DEB, X11 и нативный Wayland на Cinnamon, GNOME и KDE Plasma. Проверить клавиатурные сочетания, HiDPI, буфер обмена, Secret Service и оконное поведение. Следующий формат упаковки — AppImage после проверки зависимостей на нескольких дистрибутивах.
2. Доработать восстановление сеанса после сетевого обрыва, с ограниченными повторами и возможностью остановить попытки. Проверить полноэкранный режим с несколькими мониторами.
3. Измерить отзывчивость и передачу крупных файлов на Windows RDS и xrdp в сравнении с mstsc, FreeRDP и Remmina. Проверить фактический аппаратный декодер на Intel, AMD и NVIDIA, затем уменьшить копирование кадров и оценить вывод без копирования. [План проверок](docs/PERFORMANCE.md)
4. Добавить синхронизацию по запросу, затем опциональную фоновую. Нужны безопасное слияние независимых правок, ручное разрешение конфликтов, перенос удалений и групп. Использовать общий механизм для папки, WebDAV и SFTP, затем добавить SMB. Секреты остаются на устройствах. [Требования](docs/SYNC.md)
5. Добавить опциональный Kerberos SSO через пользовательский билет без включения ПК в домен. Проверить микрофон на Windows, затем рассмотреть принтеры, смарт-карты и USB.
6. Поддерживать русский и английский интерфейс и обе версии основных документов при добавлении функций.

## Матрица пакетов

| Цель | Пакет и проверка |
| --- | --- |
| Mint 22.3 / Ubuntu 24.04 LTS | Текущий DEB для Mint. Проверить установку из штатных репозиториев Ubuntu и запуск под X11 и Wayland. |
| Debian 13 / следующие Ubuntu LTS | Собирать отдельный DEB на каждом базовом выпуске, включая FreeRDP с нашим патчем файлового буфера. Проверять зависимости и установку в чистой системе. |
| Debian 12 | Проверить сборку с отдельным окружением GTK/libadwaita. Системный GTK 4.8 ниже требуемого GTK 4.14. Flatpak рассмотреть после проверки файлового буфера и FUSE в песочнице. |
| Arch Linux | Подготовить PKGBUILD, собирать через makepkg в чистом Arch и проверять установку через pacman. Публикацию в AUR рассмотреть после определения публичного источника. |
| RHEL | Начать с отдельного RPM для RHEL 10. Проверить AppStream, зависимости FreeRDP и разрешения FUSE при включённом SELinux. Совместимость RHEL 9 оценивать отдельно. |

Для каждого пакета проверить обновление, запуск из меню, подключение к Windows и xrdp, а также пароль, звук и передачу файлов. Установка в контейнере проверяет зависимости. Для графики, захвата клавиш, GPU и файлового буфера нужен полноценный сеанс рабочего стола.

## После стабилизации Linux

Рассмотреть Android. Общими могут стать модели профилей, шифрование, формат обмена и слияние. Интерфейс, сенсорный ввод, хранение секретов и жизненный цикл сеансов нужно адаптировать отдельно. Совместимость файлового буфера, фоновой синхронизации и Kerberos проверяется до заявления о поддержке.
